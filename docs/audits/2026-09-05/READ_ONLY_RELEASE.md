## Remaining evidence gaps

The [real-input ledger](../2026-09-04/REAL_INPUT_QUALIFICATION.md) lists unexercised cue-marker cases, authentic corrupt/future-state incidents, malformed structured documents, unavailable presentation executables, and defensive parser-response branches. ## Reproduce

Run `npm run typecheck`, then `npm run test:e2e -- --retries=0` with the public DOCX/PDF paths exported and a verified packaged executable selected. The runtime creates private `crash-corpus/provenance.json` output. Set `TELEPROMPT_REAL_CRASH_CORPUS` to that directory, then run `npm run test:real` and `npm run test:coverage`. DOCX/PDF and historical profile defaults in the real-input runner resolve to the attributed public fixtures. The full coverage command also needs the DOCX/PDF environment variables. Native checks require Xvfb, xdotool, xev, and a working Chromium sandbox.

`npm run test:stress` runs the real file workload for five minutes by default. `TELEPROMPT_STRESS_REPORT` selects its private JSON output. Do not change input files or run other memory-heavy tests while collecting a comparison. Record the ASAR hash for every measured package.
